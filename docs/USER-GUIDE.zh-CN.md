# FlashPilot 使用指南

[English](USER-GUIDE.md) · **简体中文**

用确定性引擎、CLI/MCP 和原生桌面宿主验证声明式 ECU 烧录计划。

## 当前可用状态

AGPL 引擎、CLI 和 MCP 保持免费，包含现行许可证允许的 CI 使用。规划有经验证的官方工程资产；付费版尚未开售。

## 平台与安装

桌面源码和预览路径面向 macOS、Windows、Linux。发布压缩包不表示所有适配器、ECU 和总线均已合格。

从[官方 Releases](https://github.com/turlamai/flashpilot/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

便携版 CLI 压缩包的执行路径随版本而异：已发布的 **v0.1.0 Windows ZIP** 在根目录放置 `flashpilot.exe`；包含 [Windows 压缩包目录修复（#10）](https://github.com/turlamai/flashpilot/issues/10) 的后续构建改为 `bin/flashpilot.exe`。macOS 和 Linux CLI ZIP 使用 `bin/flashpilot`。请完整解压，勿只移动可执行文件：Racket 的运行库目录布局随操作系统而不同，需要原样保留。

## 第一次使用

1. 先阅读手册，选择随库提供的模拟器和示例计划。
2. 先在不接触真实设备的情况下验证计划，检查确定性输出、失败状态和日志。
3. 使用真实硬件前，将适配器、固件、ECU 与具体资格记录匹配，并建立恢复与断电处理流程。

## 诊断命令：`udid` 与 `request`

CLI 为脚本和 Agent 提供两个读取/诊断命令。使用源码工作树时，不指定 `--transport` 即连接内置模拟 ECU：

```sh
racket app/cli.rkt udid 0xF190
racket app/cli.rkt request 22F190
```

- `udid <did>` 发送 UDS ReadDataByIdentifier（`0x22`），读取一个以十六进制表示的两字节 DID。DID 参数可写为 `F190` 或 `0xF190`。
- `request <hex>` 发送原始十六进制 UDS 请求字节。例如 `22F190` 请求读取 DID `F190`。这是**单条请求**，并非执行烧录计划。
- 默认通道是模拟 ECU；显式指定真实传输方式/地址后才会改变请求目标。连接物理设备前，必须确认试验台、适配器授权及恢复流程。示例 DID 仅演示请求格式，**不保证所有 ECU 或模拟器均支持该标识符**。

**必须联合判断 JSON 与进程退出码。** 对这两个命令，`ok` 表示请求/传输层面的结果，`positive` 表示 ECU 是否返回了 UDS 肯定响应。因此即使 `ok: true`，只要 `positive: false`，也**不能**认定诊断操作成功。`responseHex` 有可返回的响应内容时为相应十六进制文本，否则为 `null`；原始 `request` 还包含 `nrc`（存在否定响应码时返回该码，否则为 `null`），而 `udid` 结果不包含 `nrc` 字段。

例如，请求抵达模拟 ECU，但未收到肯定响应时，`udid` 可能输出：

```json
{"ok":true,"positive":false,"responseHex":null}
```

上述 `udid` 结果的进程退出码是 **1**，不是 0。`udid` 和 `request` 仅在 UDS 肯定响应时返回 **0**，非肯定结果返回 **1**；参数错误和传输初始化错误遵循 CLI 各自的错误处理路径。不要仅凭 `ok` 判定成功，也不要假设失败响应总有非空 `responseHex`。完整命令格式和退出码表可查看 `flashpilot --help`（源码方式为 `racket app/cli.rkt --help`）。本节说明当前实现语义，不代表真实 ECU 已通过适配验证。

## 数据、备份与恢复

计划文件、固件摘要、适配器版本和运行日志应一起保存。ECU 与固件恢复材料独立于应用目录保管；分享日志前删除设备标识与专有固件信息。

## 联网、密钥与隐私

真实烧录会写入连接的设备；验证或模拟结果本身并不构成真实写入授权。外部适配器与配置的端点有各自的访问和数据边界。

## 已知限制

打包模拟器验收不等于硬件在环资格。支持与证据矩阵见 #4；不承诺通用 ECU 兼容。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turlamai/flashpilot/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
